# Jev 驱动的中文地名多粒度分词器 — 设计方案

> 来源：用户 2026-09-20 粘贴的完整方案。本文件为结构完整落地稿（实现对照）。对话原文全文未能从 transcript 无截断恢复；见 docs/DESIGN_GAPS.md。

核心：程序建立字符边界和候选词图，Jev 对边界与候选语义作并行判定，再由确定性代码完成受约束解码。
Jev 接收 state + questions，返回有限选项、概率或评分；同批问题独立并行。
前置约束：Jev 当前以英语表现最佳，中文需单独验证——Jev 是可评测、可替换判定模块，不预设优于本地中文分词。

## 一、输出定义（双粒度，不可扁平混用）

### 1. 地理单元级分词
把地址串拆成完整地理单元，保留名称内部完整性。
例：江苏省南京市栖霞区仙林大道 → 江苏省 / 南京市 / 栖霞区 / 仙林大道
用途：地图搜索、地址解析、地名实体匹配。

### 2. 地名成分级分词
在完整地名内部识别专名、通名及限定成分，并保留父子关系。
例：南京市 → 南京/市；仙林大道 → 仙林/大道；广西壮族自治区 → 广西/壮族/自治区
上海市南京东路：单元层 上海市/南京东路；成分层道路内「南京」≠ 城市实体。
「名称中含有地名字符串」≠「文本提到了那个地理实体」。

阶段一：单地名与短地址串。篇章地名识别、实体链接、地理编码为扩展，不塞进分词核心。

## 二、总体架构：本地候选生成＋Jev 判定＋全局解码

流水线：原文 + 分词粒度 + 可选地域上下文 → 无损预处理与本地候选 → 字符边界/候选类型任务编译 → Jev 批量并行判定 → 候选词图受约束解码 → 地理单元 + 内部成分 + 歧义信息 → 可选实体链接/检索词扩展。

快速通道：本地已有明确、经验证的分析结果时直接返回，不调用 Jev。

职责划分：
- 本地预处理：字符定位、格式、偏移映射；不改写/补全原文
- 地名词库与规则：候选、名称结构、已知例外；不单凭命中强制语义
- Jev：切分边界、候选类型、局部歧义；不算偏移、不生成新地名、不维护全局一致性
- 解码器：选择完整一致路径；不把全部模型判断当硬事实
- 实体链接器：片段对齐地名记录；不把推断省市插回原始分词

## 三、核心算法

### 1. 最小原型
对每个字间隙提一个 Noul：「⟦CUT⟧ 位置是否应切开？」。线性问题数；适合未登录名内部边界实验。不可简单阈值 0.5 切开当生产方案。

### 2. 生产：边界分数进入候选词图
DAG：节点=字符位置；边=原文连续候选词。候选来源：地名词库及别名、本地中文分词器、构词/数字/门牌规则、未登录词连续子串；单字兜底保证连通。可借鉴 jieba 词图/DP，但改造评分与约束。

### 3. 全局路径评分
边界似然（校准后 p_i）+ 词典支持 + 结构特征；局部特征用 DP/半马尔可夫；复杂全局特征对 Top-K 重排。不可把相乘结果直接称「整句置信度」。

### 4. 硬约束与软约束
硬：覆盖原文、不重叠、不丢字、词来自原文连续片段、成分不跨父边界。
软：完整道路名保护、通名位置偏好等。勿把「省—市—区—道路」写成不可违反语法。

## 四、Jev 任务设计
- Noul：边界；Choice：实体类型 / 成分角色 / 局部合法方案竞争（含 unknown、not_entity）
- 用 ⟦CUT⟧ / ⟦span⟧ 显式标记，禁止模型数字符位置；questions 键名不可代替完整题干
- 同批并行≠共享答案；第一轮边界+疑难类型→本地解码；必要时第二轮内部成分
- Score 不作切分主决策；固定 jev-1.13.0

## 五、输出协议
POST /v1/toponyms/segment：text、input_kind∈{place_name,address,text}、granularity、return_components、可选地域上下文、top_k。
偏移 unicode_codepoint 左闭右开；状态 ok|ambiguous|degraded；原始模型概率与校准接受分分开；词库/规范/模型/校准版本与证据来源；归一化与原文偏移分离；entity_linking 默认关闭。

## 六、领域资产
词库：entity_id、canonical_name、aliases、entity_type、parent_relations、verified_components、valid_from/to、source/version；Trie 匹配。
构词规则含反例回归：南京市长江大桥、上海市南京东路、东莞市、内蒙古自治区、广西壮族自治区、南京大学（机构/场所）。
金标准：双粒度标注格式与少量样例；2k–5k 为目标规模说明，不虚构大批标注；按地名分组划分训练/测试。

## 七、评测
对照：jieba+词库、本地分词+词库、Jev 全间隙、词图+Jev+解码、快路径+选择性 Jev。
指标：候选召回/路径可达、单元跨度 F1/整串正确、成分跨度与角色 Macro-F1、未登录词、校准曲线、延迟与成本。中文任务单独校准。

## 八、部署与成本
三级：本地直接 / 选择性 Jev / 歧义或降级。控制请求规模；缓存含上下文与版本；按实际累计输入 token 测算；脱敏；公开地名与私人地址分开。

## 九、实施顺序
A 定义任务 → B 验证 Jev → C 可用系统 → D 生产优化。
第一版：字间隙 Noul＋小型词库＋本地词图解码；保留双层输出。实体链接等放核心稳定之后。
